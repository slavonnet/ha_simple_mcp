# Использование HA Simple MCP

## 1. Установка через HACS

1. Добавьте репозиторий как кастомный в HACS (тип: `Integration`).
2. Установите `HA Simple MCP`.
3. Перезапустите Home Assistant.

## 2. Первичная настройка интеграции

`Настройки -> Устройства и службы -> Добавить интеграцию -> HA Simple MCP`

Поля:

- **Адрес прослушивания** (`listen_host`)  
  Пусто по умолчанию (слушать на всех интерфейсах).
- **Порт биндинга** (`listen_port`)  
  По умолчанию `8124`.
- **Токен авторизации** (`auth_token`)  
  Если пусто — доступ без токена.
- **Пользователь API** (`ha_user`)  
  От имени кого логически разрешен доступ (рекомендуется выделенный пользователь).
- **Read-only режим** (`read_only`)  
  Блокирует все методы, кроме `GET`.
- **Таймаут** (`timeout`)  
  Таймаут upstream вызовов в секундах.
- **TTL кэша схемы** (`schema_cache_ttl`)  
  Через сколько секунд перестраивать схему инструментов.
- **Allowed scopes** (`allowed_scopes`)  
  CSV allowlist скоупов, например: `ha.api.get.*`.

## 3. MCP HTTP API

### `GET /health`

Проверка состояния сервера.

### `GET /mcp/tools`

Возвращает список MCP tools, сгенерированных динамически из маршрутов HA API.

### `POST /mcp/call`

Пример запроса:

```json
{
  "tool": "ha_get_api_states_entity_id",
  "arguments": {
    "entity_id": "light.kitchen"
  },
  "scopes": ["ha.api.get.*"]
}
```

Пример ответа:

```json
{
  "status": 200,
  "body": {
    "...": "raw HA JSON"
  }
}
```

## 4. Авторизация

Если `auth_token` задан, во все запросы к MCP серверу требуется:

```http
Authorization: Bearer <token>
```

## 5. Scope-ограничение от AI сервера

В теле `POST /mcp/call` поле `scopes` (массив строк) ограничивает доступные инструменты дополнительно к конфигурационному allowlist.

Итоговая логика:

1. Проверка allowlist интеграции (`allowed_scopes`, если задан).
2. Проверка runtime `scopes` из запроса (если переданы).

Если хотя бы одна проверка не проходит — `403 tool_scope_blocked`.
